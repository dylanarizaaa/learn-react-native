## Descripción del proyecto

Un contador parece trivial, pero reúne todo lo esencial de React Native: **estado**, **eventos táctiles**, **estilos**, **accesibilidad**, una **API nativa** (vibración) y **persistencia**. Es ideal como primer proyecto porque cada concepto se ve de inmediato en la pantalla.

Construiremos una app de una sola pantalla para contar cualquier cosa: vasos de agua, repeticiones de ejercicio o personas en un aforo.

<Step title="Escribe el hook useCounter">

Toda la lógica vive en un hook: la pantalla solo dibujará. Así podríamos tener varios contadores en la app reutilizando el mismo código.

```ts title="src/hooks/use-counter.ts"
import { useState } from 'react';
import * as Haptics from 'expo-haptics';
import Storage from 'expo-sqlite/kv-store';

type Options = { key: string; min?: number; max?: number };

function readStored(key: string, fallback: number) {
  const raw = Storage.getItemSync(key);
  const parsed = raw === null ? NaN : Number(raw);
  return Number.isFinite(parsed) ? parsed : fallback;
}

export function useCounter({ key, min = 0, max = 100 }: Options) {
  // Inicialización perezosa: leemos el valor guardado solo una vez
  const [value, setValue] = useState(() => readStored(key, min));
  const [step, setStep] = useState(1);

  function update(next: number) {
    const clamped = Math.min(max, Math.max(min, next));
    if (clamped !== next) {
      // Intentó pasar el límite: vibración de advertencia
      Haptics.notificationAsync(Haptics.NotificationFeedbackType.Warning);
    } else {
      Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
    }
    setValue(clamped);
    Storage.setItemSync(key, String(clamped));
  }

  return {
    value,
    step,
    setStep,
    atMin: value <= min,
    atMax: value >= max,
    increment: () => update(value + step),
    decrement: () => update(value - step),
    reset: () => {
      Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success);
      setValue(min);
      Storage.setItemSync(key, String(min));
    },
  };
}
```

<Step title="Crea el selector de paso">

```tsx title="src/components/step-selector.tsx"
import { Pressable, StyleSheet, Text, View } from 'react-native';

const STEPS = [1, 5, 10] as const;

export function StepSelector({ value, onChange }: { value: number; onChange: (step: number) => void }) {
  return (
    <View style={styles.row} accessibilityRole="radiogroup" accessibilityLabel="Tamaño del paso">
      {STEPS.map((step) => {
        const selected = step === value;
        return (
          <Pressable
            key={step}
            onPress={() => onChange(step)}
            accessibilityRole="radio"
            accessibilityState={{ checked: selected }}
            style={[styles.option, selected && styles.selected]}
          >
            <Text style={[styles.label, selected && styles.selectedLabel]}>+{step}</Text>
          </Pressable>
        );
      })}
    </View>
  );
}

const styles = StyleSheet.create({
  row: { flexDirection: 'row', backgroundColor: '#f1f5f9', borderRadius: 14, padding: 4 },
  option: { flex: 1, paddingVertical: 10, borderRadius: 10, alignItems: 'center' },
  selected: { backgroundColor: '#fff', boxShadow: '0 1px 3px rgba(0,0,0,0.12)' },
  label: { fontSize: 16, color: '#64748b', fontWeight: '600' },
  selectedLabel: { color: '#0f172a' },
});
```

<Step title="Construye la pantalla">

```tsx title="src/app/index.tsx"
import { Pressable, StyleSheet, Text, View } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import { StepSelector } from '@/components/step-selector';
import { useCounter } from '@/hooks/use-counter';

const MAX = 100;

export default function CounterScreen() {
  const counter = useCounter({ key: 'counter.water', max: MAX });

  return (
    <SafeAreaView style={styles.screen}>
      <Text style={styles.title}>Vasos de agua</Text>

      <Pressable
        onLongPress={counter.reset}
        delayLongPress={600}
        accessibilityRole="button"
        accessibilityLabel={`Valor actual ${counter.value}`}
        accessibilityHint="Mantén pulsado para reiniciar a cero"
      >
        <Text style={[styles.value, counter.atMax && styles.valueMax]}>{counter.value}</Text>
      </Pressable>
      {counter.atMax ? <Text style={styles.hint}>Has alcanzado el máximo ({MAX})</Text> : null}

      <View style={styles.controls}>
        <StepSelector value={counter.step} onChange={counter.setStep} />
        <Pressable
          onPress={counter.increment}
          disabled={counter.atMax}
          accessibilityRole="button"
          style={({ pressed }) => [styles.button, styles.primary, (pressed || counter.atMax) && styles.dimmed]}
        >
          <Text style={styles.primaryText}>+ Sumar {counter.step}</Text>
        </Pressable>
        <Pressable
          onPress={counter.decrement}
          disabled={counter.atMin}
          accessibilityRole="button"
          style={({ pressed }) => [styles.button, styles.secondary, (pressed || counter.atMin) && styles.dimmed]}
        >
          <Text style={styles.secondaryText}>− Restar {counter.step}</Text>
        </Pressable>
        <Text style={styles.footnote}>Mantén pulsado el número para reiniciar</Text>
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#fff', alignItems: 'center', justifyContent: 'space-between', padding: 24 },
  title: { fontSize: 20, fontWeight: '600', color: '#334155', marginTop: 24 },
  value: { fontSize: 120, fontWeight: '800', color: '#0f172a', fontVariant: ['tabular-nums'] },
  valueMax: { color: '#0284c7' },
  hint: { color: '#0284c7', fontWeight: '500' },
  controls: { alignSelf: 'stretch', gap: 12 },
  button: { paddingVertical: 18, borderRadius: 16, alignItems: 'center' },
  primary: { backgroundColor: '#0f172a' },
  secondary: { backgroundColor: '#f1f5f9' },
  dimmed: { opacity: 0.5 },
  primaryText: { color: '#fff', fontSize: 18, fontWeight: '700' },
  secondaryText: { color: '#0f172a', fontSize: 18, fontWeight: '700' },
  footnote: { textAlign: 'center', color: '#94a3b8', fontSize: 13 },
});
```

## Qué has aprendido

- **Estado y renders**: cada `setValue` vuelve a ejecutar el componente y la pantalla refleja el nuevo valor.
- **Inicialización perezosa** de `useState` para leer de almacenamiento solo una vez.
- **Hook personalizado** que separa la lógica de la interfaz ([Hooks personalizados](/docs/react-typescript/hooks-personalizados)).
- **Accesibilidad**: roles `button` y `radio`, estados y pistas para lectores de pantalla.
- **APIs nativas** con una línea gracias al SDK de Expo.
