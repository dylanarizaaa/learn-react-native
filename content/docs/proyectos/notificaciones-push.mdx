## Descripción del proyecto

Las notificaciones push son un sistema con tres participantes: **la app** (pide permiso y obtiene el token), **tu backend** (guarda tokens y decide a quién avisar) y **el servicio de push** (Expo Push Service sobre APNs y FCM). Este proyecto construye las tres piezas para una app de pedidos: avisos de cambio de estado, mensajes del repartidor y promociones opcionales.

El objetivo es que las notificaciones sean **útiles y respetuosas**: el usuario elige qué recibir, cada aviso lleva a su contenido y los tokens inválidos se limpian solos.

```ts title="features/notifications/setup.ts"
import * as Notifications from 'expo-notifications';
import { Platform } from 'react-native';

export const CHANNELS = {
  orders: { name: 'Estado de pedidos', importance: Notifications.AndroidImportance.HIGH },
  chat: { name: 'Mensajes del repartidor', importance: Notifications.AndroidImportance.MAX },
  promos: { name: 'Promociones', importance: Notifications.AndroidImportance.DEFAULT },
} as const;
export type ChannelId = keyof typeof CHANNELS;

// Con la app abierta: mostramos banner salvo para promociones
Notifications.setNotificationHandler({
  handleNotification: async (notification) => {
    const isPromo = notification.request.content.data?.channel === 'promos';
    return { shouldShowBanner: !isPromo, shouldShowList: true, shouldPlaySound: !isPromo, shouldSetBadge: true };
  },
});

export async function setupNotificationChannels() {
  if (Platform.OS === 'android') {
    for (const [id, config] of Object.entries(CHANNELS)) {
      await Notifications.setNotificationChannelAsync(id, config);
    }
  }
  // Botones en la notificación de mensajes
  await Notifications.setNotificationCategoryAsync('chat-message', [
    { identifier: 'reply', buttonTitle: 'Responder', textInput: { submitButtonTitle: 'Enviar', placeholder: 'Escribe…' } },
    { identifier: 'mark-read', buttonTitle: 'Marcar como leído', options: { opensAppToForeground: false } },
  ]);
}
```

<Step title="Permiso en contexto y registro del token">

```ts title="features/notifications/register.ts"
import Constants from 'expo-constants';
import * as Device from 'expo-device';
import * as Notifications from 'expo-notifications';
import { Platform } from 'react-native';
import { api } from '@/lib/api-client';

export async function registerDevice(): Promise<'granted' | 'denied' | 'unsupported'> {
  if (!Device.isDevice) return 'unsupported';

  let { status } = await Notifications.getPermissionsAsync();
  if (status !== 'granted') status = (await Notifications.requestPermissionsAsync()).status;
  if (status !== 'granted') return 'denied';

  const projectId = Constants.expoConfig?.extra?.eas?.projectId ?? Constants.easConfig?.projectId;
  const { data: token } = await Notifications.getExpoPushTokenAsync({ projectId });

  // El backend asocia el token al usuario autenticado (upsert por token)
  await api.post('/devices', {
    token,
    platform: Platform.OS,
    deviceName: Device.deviceName,
  });
  return 'granted';
}
```

<Step title="Navegar al tocar y responder a las acciones">

```ts title="features/notifications/use-notification-navigation.ts"
import { router } from 'expo-router';
import * as Notifications from 'expo-notifications';
import { useEffect } from 'react';
import { api } from '@/lib/api-client';

function handleResponse(response: Notifications.NotificationResponse) {
  const data = response.notification.request.content.data as { url?: string; conversationId?: string };

  if (response.actionIdentifier === 'mark-read' && data.conversationId) {
    api.post(`/conversations/${data.conversationId}/read`).catch(() => {});
    return;
  }
  if (response.actionIdentifier === 'reply' && data.conversationId && response.userText) {
    api.post(`/conversations/${data.conversationId}/messages`, { text: response.userText }).catch(() => {});
    return;
  }
  if (typeof data.url === 'string') router.push(data.url as never);
}

export function useNotificationNavigation() {
  useEffect(() => {
    // Cubre la apertura en frío: la app estaba cerrada y se abrió desde la notificación
    const last = Notifications.getLastNotificationResponse();
    if (last) handleResponse(last);

    const sub = Notifications.addNotificationResponseReceivedListener(handleResponse);
    return () => sub.remove();
  }, []);
}
```

<Step title="Envío desde el backend con lotes y recibos">

```ts title="server/push.ts"
import { Expo, type ExpoPushMessage, type ExpoPushTicket } from 'expo-server-sdk';
import { db } from './db'; // tu acceso a datos

const expo = new Expo({ accessToken: process.env.EXPO_ACCESS_TOKEN }); // opcional: seguridad de push mejorada

type Channel = 'orders' | 'chat' | 'promos';

export async function sendToUser(userId: string, channel: Channel, title: string, body: string, data: Record<string, unknown>) {
  const prefs = await db.notificationPreferences(userId);
  if (!prefs[channel]) return; // el usuario desactivó este tipo

  const tokens = (await db.deviceTokens(userId)).filter((t) => Expo.isExpoPushToken(t));
  const messages: ExpoPushMessage[] = tokens.map((to) => ({
    to,
    title,
    body,
    data: { ...data, channel },
    channelId: channel, // canal de Android
    sound: channel === 'promos' ? undefined : 'default',
    categoryId: channel === 'chat' ? 'chat-message' : undefined,
  }));

  const tickets: ExpoPushTicket[] = [];
  for (const chunk of expo.chunkPushNotifications(messages)) {
    tickets.push(...(await expo.sendPushNotificationsAsync(chunk)));
  }

  // Tokens rechazados inmediatamente
  tickets.forEach((ticket, i) => {
    if (ticket.status === 'error' && ticket.details?.error === 'DeviceNotRegistered') db.removeDeviceToken(tokens[i]);
  });

  // Guardamos los ids para consultar los recibos más tarde (por ejemplo, en 15 minutos)
  const ids = tickets.flatMap((t, i) => (t.status === 'ok' ? [{ id: t.id, token: tokens[i] }] : []));
  await db.savePushTickets(ids);
}

/** Tarea programada: comprueba la entrega real y limpia tokens caducados */
export async function checkReceipts() {
  const pending = await db.pendingPushTickets();
  for (const chunk of expo.chunkPushNotificationReceiptIds(pending.map((p) => p.id))) {
    const receipts = await expo.getPushNotificationReceiptsAsync(chunk);
    for (const [id, receipt] of Object.entries(receipts)) {
      if (receipt.status === 'error' && receipt.details?.error === 'DeviceNotRegistered') {
        const token = pending.find((p) => p.id === id)?.token;
        if (token) await db.removeDeviceToken(token);
      }
    }
    await db.markTicketsChecked(chunk);
  }
}
```

## Qué has aprendido

- **El circuito completo** de push: permiso, token, registro en el backend, envío, entrega y recibos.
- **Pedir permiso en contexto** con una pantalla que explica el valor antes del diálogo del sistema.
- **Canales de Android y preferencias** por tipo, respetadas en el servidor.
- **Acciones en la notificación** (responder, marcar como leído) sin abrir la app.
- **Fiabilidad**: lotes, tickets, recibos y limpieza de tokens inválidos.
