## Introducción conceptual

`expo-sharing` abre la **hoja de compartir del sistema** con un archivo local: el usuario elige si lo envía por correo, WhatsApp, lo guarda en Drive o lo abre con otra app. Es la forma estándar de **exportar** informes, facturas, copias de seguridad o fotos.

React Native también incluye `Share` en el núcleo, pero está pensado para **texto y URLs**. Para **archivos**, usa `expo-sharing`. En las versiones recientes, `expo-sharing` además permite **recibir** contenido compartido desde otras apps (configurándolo en el plugin).

## Ejemplo práctico

```bash
npx expo install expo-sharing expo-file-system
```

Exportar movimientos a CSV y compartirlos:

```ts title="src/services/export-csv.ts"
import { File, Paths } from 'expo-file-system';
import * as Sharing from 'expo-sharing';

type Movement = { date: string; description: string; amount: number };

function escapeCsv(value: string | number) {
  const text = String(value);
  // Comillas si contiene separador, comillas o saltos de línea
  return /[",\n;]/.test(text) ? `"${text.replace(/"/g, '""')}"` : text;
}

export function toCsv(rows: Movement[]): string {
  const header = ['Fecha', 'Descripción', 'Importe'];
  const lines = rows.map((r) => [r.date, r.description, r.amount.toFixed(2)].map(escapeCsv).join(','));
  // BOM para que Excel detecte UTF-8 (acentos y ñ)
  return '﻿' + [header.join(','), ...lines].join('\n');
}

export async function shareMovementsCsv(rows: Movement[]) {
  if (!(await Sharing.isAvailableAsync())) {
    throw new Error('Compartir no está disponible en este dispositivo');
  }

  const file = new File(Paths.cache, `movimientos-${new Date().toISOString().slice(0, 10)}.csv`);
  if (file.exists) file.delete();
  file.create();
  await file.write(toCsv(rows));

  await Sharing.shareAsync(file.uri, {
    mimeType: 'text/csv',
    dialogTitle: 'Exportar movimientos',
    UTI: 'public.comma-separated-values-text',
  });
}
```

```tsx title="src/components/export-button.tsx"
import { useState } from 'react';
import { Alert, Pressable, Text } from 'react-native';
import { shareMovementsCsv } from '@/services/export-csv';

export function ExportButton({ movements }: { movements: Parameters<typeof shareMovementsCsv>[0] }) {
  const [busy, setBusy] = useState(false);

  async function handlePress() {
    try {
      setBusy(true);
      await shareMovementsCsv(movements);
    } catch (error) {
      Alert.alert('No se pudo exportar', error instanceof Error ? error.message : 'Error desconocido');
    } finally {
      setBusy(false);
    }
  }

  return (
    <Pressable onPress={handlePress} disabled={busy || movements.length === 0} accessibilityRole="button">
      <Text>{busy ? 'Preparando…' : 'Exportar CSV'}</Text>
    </Pressable>
  );
}
```

Para compartir solo texto o un enlace, el `Share` del núcleo es suficiente:

```ts
import { Share } from 'react-native';

await Share.share({ message: 'Mira esta receta: https://ejemplo.com/recetas/42' });
```

## Explicación del código

- **`isAvailableAsync()`** comprueba si el dispositivo puede compartir (en web depende del navegador).
- **El archivo se crea en `Paths.cache`**: es temporal y el sistema puede limpiarlo; no ocupa espacio en las copias de seguridad.
- **`escapeCsv`** sigue las reglas del formato CSV: si un campo contiene comas, comillas o saltos de línea, se rodea de comillas y se duplican las comillas internas.
- **`'﻿'`** (BOM) hace que Excel abra el archivo como UTF-8 y muestre bien los acentos.
- **`mimeType`** (Android y iOS) y **`UTI`** (iOS) indican el tipo de archivo para que el sistema ofrezca las apps adecuadas. `dialogTitle` se muestra en Android y web.
- **`shareAsync`** se resuelve cuando se cierra la hoja de compartir; no indica si el usuario completó el envío.

## Buenas prácticas

- **Nombra los archivos de forma descriptiva** y con fecha: es lo que verá el destinatario.
- **Limpia archivos temporales antiguos** si generas exportaciones con frecuencia.
- **Deshabilita el botón** mientras se prepara el archivo para evitar dobles exportaciones.

### Errores comunes

- Compartir una URL remota con `shareAsync`: debe ser un archivo local (`file://`). Descárgalo primero con `File.downloadFileAsync`.
- Usar `;` o `,` sin escapar en campos de texto del CSV.

### Cuándo usar otra solución

Para generar PDFs a partir de HTML usa `expo-print` (`printToFileAsync`) y después compártelo con `expo-sharing`. Para guardar directamente en la galería de fotos, usa `expo-media-library`.
