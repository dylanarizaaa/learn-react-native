## Introducción conceptual

El `Modal` del núcleo tiene un problema para un kit: cuando `visible` pasa a `false`, desaparece **inmediatamente**, sin animación de salida. Además, la animación `slide` mueve también el fondo semitransparente. Un *bottom sheet* de calidad necesita:

1. Fondo que aparece con un **fundido** y panel que **sube desde abajo**.
2. **Animación de salida** completa antes de desmontar.
3. Cierre con **toque en el fondo**, **botón atrás de Android** y **gesto de deslizar**.
4. Respetar el **área segura** inferior y la accesibilidad.

Lo resolvemos separando dos conceptos: `open` (lo que quiere el padre) y `mounted` (si el `Modal` sigue en pantalla mientras termina la animación de salida).

```ts title="src/components/ui/use-disclosure.ts"
import { useCallback, useState } from 'react';

/** Estado abierto/cerrado con acciones estables */
export function useDisclosure(initial = false) {
  const [isOpen, setIsOpen] = useState(initial);
  const open = useCallback(() => setIsOpen(true), []);
  const close = useCallback(() => setIsOpen(false), []);
  const toggle = useCallback(() => setIsOpen((v) => !v), []);
  return { isOpen, open, close, toggle };
}
```

```tsx title="src/components/ui/sheet.tsx"
import { useEffect, useState, type ReactNode } from 'react';
import { Modal, Pressable, View, useWindowDimensions } from 'react-native';
import { GestureDetector, GestureHandlerRootView, usePanGesture } from 'react-native-gesture-handler';
import Animated, { Easing, interpolate, useAnimatedStyle, useSharedValue, withTiming } from 'react-native-reanimated';
import { useSafeAreaInsets } from 'react-native-safe-area-context';
import { scheduleOnRN } from 'react-native-worklets';
import { cn } from '@/lib/cn';
import { Text } from './text';

export { useDisclosure } from './use-disclosure';

type SheetProps = {
  open: boolean;
  onClose: () => void;
  title?: string;
  children: ReactNode;
  className?: string;
};

const DURATION = 260;

export function Sheet({ open, onClose, title, children, className }: SheetProps) {
  const { height } = useWindowDimensions();
  const insets = useSafeAreaInsets();
  const [mounted, setMounted] = useState(open);
  const progress = useSharedValue(0); // 0 = oculto, 1 = visible
  const dragY = useSharedValue(0);

  // Montar al abrir; animar la salida antes de desmontar al cerrar
  useEffect(() => {
    if (open) {
      setMounted(true);
      dragY.value = 0;
      progress.value = withTiming(1, { duration: DURATION, easing: Easing.out(Easing.cubic) });
    } else if (mounted) {
      progress.value = withTiming(0, { duration: 200 }, (finished) => {
        if (finished) scheduleOnRN(setMounted, false);
      });
    }
  }, [open]); // eslint-disable-line react-hooks/exhaustive-deps

  const pan = usePanGesture({
    activeOffsetY: 10,
    onUpdate: (e) => {
      'worklet';
      dragY.value = Math.max(0, e.translationY); // solo hacia abajo
    },
    onDeactivate: (e) => {
      'worklet';
      if (dragY.value > 120 || e.velocityY > 1000) scheduleOnRN(onClose);
      else dragY.value = withTiming(0, { duration: 150 });
    },
  });

  const backdropStyle = useAnimatedStyle(() => ({ opacity: progress.value * 0.5 }));
  const panelStyle = useAnimatedStyle(() => ({
    transform: [{ translateY: interpolate(progress.value, [0, 1], [height, 0]) + dragY.value }],
  }));

  if (!mounted) return null;

  return (
    <Modal visible transparent animationType="none" statusBarTranslucent navigationBarTranslucent onRequestClose={onClose}>
      {/* El Modal se renderiza fuera del árbol: necesita su propia raíz de gestos */}
      <GestureHandlerRootView style={{ flex: 1 }}>
        <Animated.View className="absolute inset-0 bg-black" style={backdropStyle}>
          <Pressable className="flex-1" onPress={onClose} accessibilityLabel="Cerrar" accessibilityRole="button" />
        </Animated.View>

        <Animated.View
          style={[panelStyle, { paddingBottom: Math.max(insets.bottom, 16) }]}
          className={cn('absolute inset-x-0 bottom-0 max-h-[85%] rounded-t-3xl bg-card px-5 pt-2', className)}
          accessibilityViewIsModal
        >
          <GestureDetector gesture={pan}>
            <View className="items-center py-3" accessibilityLabel="Desliza hacia abajo para cerrar">
              <View className="h-1.5 w-10 rounded-full bg-border" />
            </View>
          </GestureDetector>
          {title ? (
            <Text variant="heading" className="mb-3">
              {title}
            </Text>
          ) : null}
          {children}
        </Animated.View>
      </GestureHandlerRootView>
    </Modal>
  );
}
```

```tsx title="Uso: menú de acciones"
import { View } from 'react-native';
import { Button, Sheet, useDisclosure } from '@/components/ui';

export function OrderActions({ onDuplicate, onCancel }: { onDuplicate: () => void; onCancel: () => void }) {
  const sheet = useDisclosure();

  return (
    <>
      <Button variant="outline" onPress={sheet.open}>
        Más acciones
      </Button>
      <Sheet open={sheet.isOpen} onClose={sheet.close} title="Acciones del pedido">

          <Button variant="secondary" fullWidth onPress={() => { sheet.close(); onDuplicate(); }}>
            Duplicar pedido
          </Button>
          <Button variant="destructive" fullWidth onPress={() => { sheet.close(); onCancel(); }}>
            Cancelar pedido
          </Button>
        </View>
      </Sheet>
    </>
  );
}
```

## Explicación del código

- **`open` vs `mounted`**: el padre controla `open`. Al pasar a `false`, el componente sigue montado mientras `progress` anima hacia 0; el callback de `withTiming` (que se ejecuta en el hilo de UI) llama a `setMounted(false)` mediante `scheduleOnRN`.
- **`progress`** es un único valor de 0 a 1 del que derivan el fondo (opacidad hasta 0.5) y el panel (`translateY` desde la altura de la ventana hasta 0).
- **`animationType="none"`**: desactivamos la animación del `Modal` nativo para controlar nosotros fondo y panel por separado.
- **Tres formas de cerrar**: el `Pressable` del fondo, `onRequestClose` (botón atrás de Android) y el gesto: si se arrastra más de 120 puntos o con velocidad alta, llamamos a `onClose`.
- **`GestureHandlerRootView` dentro del `Modal`**: los modales nativos se renderizan en otra jerarquía de vistas, por eso necesitan su propia raíz para que los gestos funcionen.
- **El gesto solo se asigna al asa** (la barra superior): así el contenido puede tener su propio scroll (por ejemplo, una lista en el `Select`) sin conflictos.
- **`paddingBottom` con `insets.bottom`** evita que los botones queden bajo la barra de gestos.
- **`accessibilityViewIsModal`** hace que VoiceOver ignore el contenido de detrás.

## Buenas prácticas

- **Contenido breve**: si la hoja necesita desplazarse mucho o tiene varios pasos, probablemente debería ser una pantalla (ruta modal de Expo Router).
- **Cierra la hoja antes de navegar** o de abrir otra superposición.
- **Respeta "reducir movimiento"**: puedes acortar o eliminar la animación con `useReducedMotion()`.

### Errores comunes

- Olvidar `onRequestClose`: el botón atrás de Android no cierra la hoja.
- Gestos que no funcionan dentro del modal por no añadir `GestureHandlerRootView`.
- Abrir un segundo `Modal` encima del primero en iOS: cierra uno antes de abrir el otro.

### Cuándo usar otra solución

Para hojas con varios puntos de anclaje (25 %, 50 %, 90 %), teclado integrado y listas largas con scroll vinculado, una librería especializada de bottom sheets ahorra mucho trabajo. Para formularios completos, usa una ruta con `presentation: 'modal'` o `'formSheet'` en Expo Router.
